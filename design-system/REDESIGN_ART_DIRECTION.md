# Nocturne Sakura — Art Direction

## Premise

«Наша маленькая вселенная» ощущается как одна короткометражная любовная сцена, которая раскрывается через пять сменяющих друг друга материалов: чернильный космос, японский альбом, лунный сад, лакированная коробка и рассвет под сакурой. Сцены должны быть разными по фактуре, но собраны одним ритмом света: глубокая тень → теплый розовый отблеск → золотая точка.

Один меморабельный элемент на весь опыт — круглая фотография в тонкой орбитальной рамке. Она повторяется как «спутник» в ключевых сценах и получает собственный shared-element переход.

## Design tokens

### Color

- `--ink-950: #0b0815` — космическая тень, основной фон.
- `--ink-900: #151024` — второй план и глубокие панели.
- `--plum-800: #2c1b3d` — бумажные и садовые тени.
- `--rose-dust: #d889aa` — сакура, активные состояния, мягкий свет.
- `--petal-light: #f6c5d8` — фотография, выделенный текст.
- `--moon-gold: #e7bf7d` — точки навигации, звёзды, края бумаги.
- `--paper: #f4eee8` — скрапбук и письмо.
- `--paper-ink: #34243a` — текст на светлых материалах.
- `--mist: rgba(245, 222, 234, .12)` — полупрозрачные слои.

Золотой цвет используется редко: максимум в 1–2 акцентах на viewport. Розовый не должен превращать всю сцену в градиент.

### Typography

- Display: **Playfair Display** 600/700 — крупные фразы, 8–12vw, с контрастными переносами.
- Text: **Source Serif 4** 400/500 — любовное письмо, подписи и пояснения, 16–18px/1.6.
- Utility: **Manrope** 600 — короткие управляющие подписи, 11–12px, sentence case; избегать постоянного uppercase.
- Handwritten accent: **Parisienne** только для подписи или одного личного акцента, не для больших блоков.

Заголовки должны быть короткими, с естественным переносом; ширина строки 40–68 символов на desktop и 28–42 на iPhone.

## Composition by chapter

### 01 — Orbit / first light

Полотно 100dvh, без карточек. В центре — крупная фраза и фотография; звёзды образуют редкую дугу, ведущую к CTA. Многослойное небо состоит из 3 медленных параллакс-слоёв, один «орбитальный» световой луч проходит за фотографией.

```text
┌──────────────────────────────┐
│  01/05             paw  sound│
│                              │
│          ✦  .       ✧        │
│       [large phrase]         │
│          (photo)             │
│  star trail      CTA          │
└──────────────────────────────┘
```

### 02 — Paper / memory table

Сцена становится светлее, фон — волокнистая бумага с тонкой сеткой полей. Карточки не стоят ровной сеткой: они складываются в раскрытый альбом с центральной линией переплёта. На desktop пять Polaroid-слоёв слегка пересекаются; на mobile — горизонтальный snap-track с видимым «следующим листом».

```text
┌──────────┬──────────┬──────────┐
│ polaroid │  binding │ polaroid │
│          │  counter │          │
│   ← page │  → page  │          │
└──────────┴──────────┴──────────┘
```

### 03 — Garden / hidden heart

Мягкий рисованный сад на синей бумаге: луна, тёмный пруд, сакура, фонарь и травы с отдельными слоями глубины. Сердца встроены в объекты (лепесток, фонарь, лист, отражение), а не лежат поверх сцены. Каждое найденное сердце даёт короткий световой импульс от точки нажатия; созвездие появляется только после пятого.

### 04 — Lacquer / gift box

Почти чёрная сцена с единственным тёплым источником под коробкой. Коробка имеет три визуальных плана: основание, крышка, лента. При открытии камера слегка приближается, тени меняются, причины любви входят веером на бумажных фрагментах, а не появляются одинаковой сеткой.

### 05 — Dawn / sakura finale

Самая широкая сцена: ночной градиент уходит в розово-персиковый рассвет. Ветка сакуры крупная и немного размытая на переднем плане; фотография — единственный резкий центр. Фразы появляются последовательно в одном «кадре», с мягким затемнением между ними; после четвёртой фразы всё лишнее отступает и остаётся только признание.

## Motion language

- Вход: 700–1000ms, `cubic-bezier(.22, 1, .36, 1)`; движение снизу вверх максимум 20px.
- Выход: 450–650ms, быстрее входа; только opacity + transform.
- Параллакс: 3 слоя, `translate3d`, амплитуда 4–12px; отключить при `prefers-reduced-motion`.
- Tap feedback: scale 0.97 → 1.0 за 160ms, без layout shift.
- Смена главы: затемнение через общий центр света (фотография/луна/коробка), без резкого snap.
- Фоновые частицы ограничить 18–24 на iPhone; выключать, когда вкладка скрыта.
- Не анимировать одновременно более двух главных объектов.

## Material and lighting rules

- Космос: diffuse bloom, без неоновых обводок.
- Бумага: grain/noise на псевдоэлементе с opacity ≤ .07, цветные пятна только в углах.
- Сад: плоские иллюстративные слои с одним мягким источником света.
- Коробка: тень от крышки и один бликовый край, без пластикового 3D.
- Финал: свет сакуры — warm rim, тени остаются холодными.

## Responsive and a11y

- Base mobile 375–430px, затем 768/1024/1440.
- Все интерактивные зоны минимум 44×44px с промежутком 8px.
- Критический текст минимум 16px, line-height 1.5.
- Fixed chrome учитывает `env(safe-area-inset-top/bottom)`.
- Видимый focus-ring 2px `--moon-gold`, escape закрывает модальные окна.
- Для reduced motion оставить финальные состояния и текстовую последовательность; не скрывать содержание.
- Не использовать emoji как интерфейсные иконки: только Lucide/SVG.

## Anti-template check

Перед каждым визуальным проходом удалить хотя бы один декоративный эффект, который не помогает сюжету. Не использовать: одинаковые glass-карточки во всех главах, бесконечные фиолетовые градиенты, all-caps eyebrows в каждой сцене, случайный neon glow, одинаковые кнопки и сетку из одинаковых блоков.
